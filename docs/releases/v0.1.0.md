# DWorkBench v0.1.0

首个公开发布版本：面向团队的多主机 Linux 日志工作台，部署目标为 Windows Server 2022 x64，通过浏览器访问。

## 下载与安装

- `DWorkBench-v0.1.0-win-x64.zip`：包含自包含运行时、前端、安装脚本、文档和许可证。
- `DWorkBench-v0.1.0-win-x64.zip.sha256`：配套校验值。
- `Verify-Package.ps1`：解压前的独立 SHA-256 校验脚本，包内也有一份。
- `QUICKSTART.zh-CN.md`：可独立下载的快速安装说明，包内也有一份。

准备 PostgreSQL 17 和组织信任的 HTTPS RSA 证书，校验 ZIP 后完整解压，双击 **`Install.cmd`**。向导逐项询问配置，不必手写数据库连接字符串、证书创建命令或 Windows 服务安装命令。目标 VM 不需要 SDK、Node.js 或 WSL。

安装材料与离线步骤见包内 `QUICKSTART.zh-CN.md`、`DEPLOYMENT.md`。构建来源见 `release-info.json`。

## 主要功能

- 本地账号、团队角色、主机和日志组权限，以及操作审计。
- 共享主机、日志源及跨主机日志组；SSH 指纹固定，SFTP 渐进扫描、筛选和分页。
- 最多关注四个文件，同时展开一到两个阅读窗格；后台摘要、规则命中、独立暂停和冻结。
- 文本、通配符、正则包含/排除和上下文筛选；自动、纯文本、JSON 字段及自定义等级提取。
- 同一远端文件共享读取，每位用户独立授权和有界缓冲；原始文件下载。
- 按账号保存最近工作台，刷新或重新登录后按需恢复接收。

Linux 目标只需已有 SSH/SFTP 服务和日志读取权限，无需 Python、Shell 执行权限、Agent 或上传程序。

## 随包安装工具

- `Install.cmd` / `Start-Install.ps1`：Windows PowerShell 5.1 交互向导、UAC 提权、证书选择/导入与独立保护证书备份。
- `Initialize-Database.ps1`：调用已有 `psql` 创建业务账号和空库；遇到已有对象停止，不重置或删除数据。
- `Install-Windows.ps1`：支持参数化安装/更新 Windows 服务、目录权限、证书私钥访问和 HTTPS 防火墙规则。
- `Check-Installation.ps1`：只读检查服务与 HTTPS 健康接口，保留证书验证。
- `Verify-Package.ps1`：包内容 SHA-256 校验。

PostgreSQL 的安装、监听和认证配置，以及组织 DNS、CA 信任仍由管理员准备。脚本不下载或安装远端依赖。

## 数据兼容与升级

本版数据库 schema 为 **2**。历史文档的 0.7、0.8、0.9 是内部迭代编号，不是此前公开发行版本。

已有内部版本升级需保留原数据库、DataRoot、key ring 和凭据保护证书。schema 1 会增量升级到 2；回滚旧程序时需恢复匹配的数据库备份。旧名称 LogDesk 的持久化加密标识、数据库配置和同账号浏览器草稿保留兼容；Windows 服务迁移按部署文档完成，升级后重新登录。

## 验证与已知限制

发布流水线要求同一提交的 Windows、Ubuntu 和 PostgreSQL 检查通过后，使用该次 CI 的 Windows 发布包创建 Release。实际运行结果以标签的 GitHub Actions 记录为准；历史覆盖与结果在包内 `VALIDATION.md`、`PERFORMANCE.md`。

- 未在用户的目标 Windows Server 2022 VM 上实际执行服务迁移、组织证书配置或断网安装；上线前需在目标环境完成安装和业务验收。
- 按可信内网主机设计。普通 SFTP 的路径检查不提供对恶意并发符号链接替换的原子隔离。
- SFTP 轮询无法保证捕获快速截断重写、内容相同的替换或轮询间多次轮转；断线后恢复最近快照，不补齐全部历史。
- 流式筛选只作用于当前保留内容，不搜索整个远端文件；UTF-16/UTF-32 原文件可下载，暂不支持流式解码。
- 单应用进程与单 VM 部署；重启会中断流和下载。容量需按实际主机、日志速率与网络验收。
- 尚未提供 SSO、Ansible、跳板机、任意命令终端或审计/元数据的自动保留期清理。
